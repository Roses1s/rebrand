## 4. Что решено НЕ делать

- **«Терминал диспетчера»** — тёмная диспетчерская тема. Отвергнута.
- **«Soft SaaS» индиго** — «близко, но всё равно не то». Не возвращать ни
  бумажный фон с оранжевым рельсом, ни серо-голубой индиго.
- **Блок «Команда» и рейтинг менеджеров в панели** — вид от менеджера, панель
  без командных блоков.
- **Фильтр «Все менеджеры» на доске** — доска только своя.
- **Автопарк, заявки на перевозку как отдельная логистика** — не рисуем.
- **Вход и авторизация** — макет открывается сразу.
- **Настоящий бэкенд, тесты, Storybook** — это витрина дизайна, не приложение.

## 5. Известные ограничения

1. **Браузера в песочнице нет** — визуальную проверку делает владелец; агент
   проверяет сборкой, серверным рендером и `curl`.
2. **Логотип визуально не проверен** — в песочнице нет рендерера SVG
   (`cairo`, `resvg` и `skia` не ставятся). Цвет задаёт маска, поэтому он
   гарантированно совпадает с текстом, но форму смотрел только владелец.
3. **Роль переключается с перезагрузкой страницы** — `IS_ADMIN` читается при
   импорте `data.js`.
4. **localStorage без версии схемы для темы и плотности** — при смене формата
   поднимать ключ (`v1` → `v2`), иначе у владельца останутся старые данные.
5. **Демо-данные вымышленные**, суммы и названия компаний не связаны с рабочей CRM.

## 9. Перенос в рабочую CRM

- **Этапы и порядок лидов** — API этапов (CRUD + позиция) и эндпойнт перемещения;
  на существующие ручки ложится почти без изменений.
- **Задачи** — новая сущность: миграция, модель, API (тип, заголовок, лид, срок,
  ответственный, статус).
- **Аналитика** — эндпойнт отчётов; остальное считается из лидов и заявок.
- Вёрстка переносится на компонентах рабочего проекта, бренд уже общий.
