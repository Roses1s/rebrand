# CRM Детроид — макет интерфейса

Макет нового интерфейса для CRM Детроид (транспортная компания). Это **не копия**
рабочей системы: вёрстка и оформление собраны с нуля, но повторяют все её функции.
Бэкенда нет — данные живут в браузере.

- Дизайн-план и принятые решения: [`PLAN.md`](PLAN.md)
- Матрица паритета «ничего не теряем»: [`PARITY.md`](PARITY.md)

## Что это

- Светлая лавандовая тема и тёмная, три акцента, две плотности.
- Роль **менеджера** по умолчанию: своя доска, свои задачи и заявки, лиды коллег — усечённо.
- Роль **администратора** включается в настройках — появляется раздел «Администрирование».
- Воронка с перетаскиванием карточек и собственным редактором этапов.
- Адаптив до телефона: панель выезжает по кнопке, воронка идёт вертикальными секциями.
- Входа и авторизации нет: приложение открывается сразу внутри системы.

## Быстрый старт

Нужен Node.js LTS с [nodejs.org](https://nodejs.org) (MSI, `winget` не требуется).

```bash
npm install
npm run dev
```

Открыть `http://localhost:5173`. Проверка production-сборки:

```bash
npm run build
npm run preview
```

| Маршрут | Что там |

| `/crm/leads/:id` | Карточка лида: этапы, клиент, заявки, файлы, история |
| `/customers` | Клиенты: поиск, сегменты, приватность лидов коллег |

| `/analytics` | Личная аналитика: период, воронка, поступление, крупные сделки |

| `/kit` | Витрина дизайн-системы |

## Воронка: перетаскивание и этапы

**Перетаскивание** (`@dnd-kit/core` + `@dnd-kit/sortable`):

- карточку можно перенести на любой этап и поставить в нужное место внутри этапа;
- линия вставки показывает точку, куда встанет карточка, пустая колонка — слот «Отпустите здесь»;
- исходная карточка тускнеет, призрак поднимается над доской с наклоном и тенью;
- мышь — срабатывание после 6 px, палец — долгое нажатие 160 мс, клавиатура — Tab, Space, стрелки, Space, Esc;
- бросок мимо доски и на прежнее место ничего не меняет; после переноса клик не открывает карточку;
- порядок сохраняется и восстанавливается после перезагрузки.

**Этапы** — карточка «Моя воронка» в настройках либо кнопка «⋮» в шапке колонки:

- создать, переименовать, задать подсказку, выбрать цвет из восьми, переставить стрелками, удалить;
- удаление этапа переносит его лиды на соседний этап; последний этап удалить нельзя;
- этапы принадлежат менеджеру: правки не затрагивают доски коллег.

## Роли и данные

| Ключ в localStorage | Что хранит |
|---|---|
| `crm.leads.<id>.v1` | Лиды менеджера, их этап и позиция |
| `crm.stages.<id>.v1` | Этапы воронки менеджера |
| `crm.theme` | Светлая или тёмная тема |
| `crm.accent` | Акцент: индиго, фиолетовый, изумрудный |
| `crm.density` | Плотность интерфейса |
| `crm.role` | `manager` или `admin` |
| `crm.funnel.view` | Канбан или список |

Сброс к демо-набору: **Настройки → «Сбросить мою воронку»**. Роль меняется там же,
страница перезагружается.

## Дизайн-система

- `src/styles/tokens.css` — цвета, радиусы, тени, типографика, тёмная тема и акценты.
- `src/styles/base.css` — сброс, фокус, шрифты, скроллбары.
- `src/styles/ui.css` — кнопки, поля, чипы, бейджи, статусы, таблицы, модалки, скелетоны.
- `src/styles/shell.css` — панель, верхняя строка, адаптив.
- `src/styles/board.css` — канбан, карточки лидов, состояния перетаскивания.
- `src/styles/pages.css` — экраны: таблицы, карточки, графики, админка.
- `src/styles/compact.css` — компактный масштаб поверх готовых стилей, подключается последним.
- `/kit` — живая витрина компонентов.

Шрифты: Inter Tight для заголовков, Inter для интерфейса, JetBrains Mono для чисел и ИНН.

## Перед показом

1. `npm run build` проходит без ошибок.
2. Воронка: перетаскивание мышью, пальцем и с клавиатуры; линия вставки на месте.
3. Пустая колонка показывает слот, а не пустоту.
4. Этапы: создание, переименование, цвет, порядок, удаление с переносом лидов.
5. Тёмная тема: панель, таблицы, карточка лида, аналитика, админка.
6. Телефон: меню выезжает, воронка вертикальная, модалки снизу.
7. Перезагрузка страницы сохраняет этапы, лиды и порядок.

## Что осталось для переноса в рабочую CRM

Вёрстка готова, поведение подключается к вашему API:

- глобальный поиск `⌘K` и состояние поиска в адресе страницы;
- открытие доски сотрудника из админки;
- диалоги редактирования пользователей и бухгалтеров;
- ошибки API с кнопкой «Повторить», догрузка списков;
- **Задачи** требуют новой сущности и API: тип, заголовок, лид, срок, ответственный, статус;
- **Аналитика** — эндпойнта отчётов; остальное считается из существующих лидов и заявок.
