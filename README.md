# ТрансЛайн CRM

HTML-прототип CRM для логистики. Главная страница — канбан-воронка лидов.

## Возможности
- Канбан с этапами: **Новый → Перезвонить → Вышел на ЛПР → Потенциальный → Уехали → Ждем заявку**
- Перетаскивание карточек между этапами (drag & drop)
- Светлая и тёмная тема (переключатель в шапке, выбор запоминается)
- Поиск по компании, контакту, маршруту и менеджеру + фильтр по менеджеру
- KPI-панель: количество лидов, сумма воронки, средний чек, конверсия
- Карточка лида в боковой панели со сменой этапа
- Создание нового лида через модальное окно
- Разделы вне главной страницы — заглушки «в разработке»

## Как открыть у себя

### Вариант 1. Без установки чего-либо (самый простой)
Скачайте проект целиком и откройте **`crm-standalone.html`** двойным щелчком —
это весь сайт в одном файле (стили и скрипты внутри). Ничего устанавливать не нужно.

Можно открыть и `index.html`, но тогда рядом должна лежать папка `assets/`.

### Вариант 2. Настоящий localhost без установок (Windows)
Двойной щелчок по **`Запустить на Windows.bat`** → откроется браузер с
`http://localhost:8000`. Сервер работает на встроенном Windows PowerShell,
права администратора не нужны. Остановка — `Ctrl + C` в окне консоли.

Если порт занят, скрипт сам возьмёт 8080 / 3000 / 5500.

### Вариант 3. Через Node.js (Windows / macOS / Linux)
```powershell
node serve.mjs          # http://localhost:3000
node serve.mjs 8080     # другой порт
npm start               # то же самое через npm
```

### Вариант 4. Через Python
```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

### Что-то не работает
| Симптом | Решение |
|---|---|
| `node` не распознан | Node.js не установлен — используйте вариант 1 или 2 |
| `EADDRINUSE` / порт занят | `node serve.mjs 3001` или перезапустите bat-файл |
| Белая страница | Откройте `crm-standalone.html` — он не зависит от папки `assets/` |
| Не видно изменений | `Ctrl + F5` (жёсткая перезагрузка) |

## Структура
```
index.html                  — разметка приложения (со внешними assets)
assets/styles.css           — стили, темы, адаптив
assets/app.js               — данные лидов и логика воронки
crm-standalone.html         — собранная версия «всё в одном файле»
build.mjs                   — сборка crm-standalone.html из index.html + assets
serve.mjs                   — локальный сервер на Node.js (без зависимостей)
serve.ps1                   — локальный сервер на Windows PowerShell (без установок)
Запустить на Windows.bat    — двойной клик: поднимает сервер и открывает браузер
```

## Разработка
Правьте `index.html`, `assets/styles.css`, `assets/app.js`, затем пересоберите автономную версию:

```bash
node build.mjs
```
