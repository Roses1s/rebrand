# ТрансЛайн CRM

HTML-прототип CRM для логистики. Главная страница — канбан-воронка лидов.

## Возможности
- Канбан с этапами: **Новый → Перезвонить → Вышел на ЛПР → Потенциальный → Уехали → Ждем заявку**
- Перетаскивание карточек между этапами (drag & drop)
- Светлая и тёмная тема (переключатель в шапке, выбор запоминается)
- Поиск по компании, контакту, маршруту и менеджеру + фильтр по менеджеру
- KPI-панель: количество лидов, сумма воронки, средний чек, конверсия
- Карточка лида в боковой панели со сменой этапа
- Создание нового лида через модальное окно
- Разделы вне главной страницы — заглушки «в разработке»

## Запуск
Откройте `index.html` или поднимите статический сервер:

```bash
python3 -m http.server 8000
```

## Структура
```
index.html        — разметка приложения
assets/styles.css — стили, темы, адаптив
assets/app.js     — данные лидов и логика воронки
```

## Запуск на Windows (Node.js)

1. Установите Node.js LTS с [nodejs.org](https://nodejs.org) (если ещё не стоит), проверьте:
   ```powershell
   node -v
   ```
2. Откройте папку проекта и запустите один из вариантов:

   ```powershell
   # вариант 1 — встроенный мини-сервер (ничего устанавливать не нужно)
   node serve.mjs

   # вариант 2 — через npm-скрипт
   npm start

   # вариант 3 — на другом порту, если 3000 занят
   node serve.mjs 8080
   ```
3. Откройте в браузере **http://localhost:3000**
4. Остановить сервер — `Ctrl + C` в окне терминала.

### Варианты проще
- Двойной клик по `index.html` — сайт откроется напрямую, без сервера (`file://`).
- VS Code → расширение **Live Server** → правый клик по `index.html` → *Open with Live Server*.
- Любой другой статический сервер: `npx serve .` или `python -m http.server 8000`.

### Если что-то не работает
- `node` не распознан → переустановите Node.js и перезапустите терминал (PATH обновится).
- `EADDRINUSE` (порт занят) → `node serve.mjs 3001`.
- Открылась старая версия → `Ctrl + F5` (жёсткая перезагрузка).
- Страница белая → проверьте, что запускали команду именно в папке проекта (там, где лежит `index.html`).
