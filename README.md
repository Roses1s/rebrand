# ТрансЛайн CRM

CRM для логистики на **React 19 + Vite**. Проект собран с чистого листа: пока это каркас —
роутинг, темы, меню и заготовки страниц. Дальше наполняем страницы данными и логикой.

## Что уже есть
- Vite 8 + React 19, мгновенная горячая перезагрузка
- Роутинг (`react-router`): Дашборд, Лиды, Заявки, Грузы
- Светлая и тёмная темы, выбор запоминается в `localStorage`, по умолчанию — системная
- Каркас интерфейса: сайдбар с группами меню, шапка с переключателем темы и профилем, адаптив (мобильное меню)
- Дизайн-токены в CSS-переменных (`src/styles/tokens.css`) — цвета и радиусы меняются в одном месте
- Страницы-заглушки с описанием того, что на них появится

## Требования

**Node.js 20.19+ или 22 LTS** — без него React/Vite не запустятся.
Если Node ещё нет, установите одной командой в PowerShell:

```powershell
winget install OpenJS.NodeJS.LTS
```

После установки закройте и снова откройте терминал (PATH обновится), проверьте:

```powershell
node -v
npm -v
```

## Запуск

```powershell
cd путь\к\проекту
npm install      # один раз, ставит react, react-dom, react-router, vite
npm run dev      # дев-сервер
```

Откройте **http://localhost:5173** — страница перезагружается сама при сохранении файлов.
Остановить сервер — `Ctrl + C` в терминале.

### Другие команды

```powershell
npm run build    # production-сборка в папку dist
npm run preview  # локальный просмотр собранной версии
```

## Структура

```
index.html                  — HTML-шаблон Vite (точка входа)
vite.config.js              — конфиг дев-сервера (порт 5173)
src/main.jsx                — монтирование React, провайдеры, роутер
src/App.jsx                 — каркас страницы: сайдбар, шапка, роуты
src/theme/ThemeProvider.jsx — контекст темы (светлая/тёмная + localStorage)
src/components/
  Sidebar.jsx               — боковое меню
  Topbar.jsx                — шапка с переключателем темы и профилем
  Icon.jsx                  — набор SVG-иконок
src/pages/
  DashboardPage.jsx         — дашборд-обзор проекта
  LeadsPage.jsx             — заглушка «Лиды»
  RequestsPage.jsx          — заглушка «Заявки»
  TripsPage.jsx             — заглушка «Грузы»
  Placeholder.jsx           — универсальная заглушка страницы
src/styles/
  tokens.css                — цвета, тени, радиусы (светлая/тёмная темы)
  base.css                  — сброс стилей, типографика, скроллбары
  layout.css                — сайдбар, шапка, контент, адаптив
  components.css            — кнопки, чипы, аватары, переключатель темы
  pages.css                 — блоки страниц (hero, карточки, панели)
```

## Как добавлять страницы
1. Создайте компонент в `src/pages/`.
2. Добавьте маршрут в `src/App.jsx` (`<Route path="/clients" element={<ClientsPage />} />`)
   и запись в объект `META` — оттуда берутся заголовок в шапке и `<title>`.
3. Пункт меню — в массиве `NAV` в `src/components/Sidebar.jsx`
   (уберите `is-soon`, добавив `to: '/clients'`).
