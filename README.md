# Макет новой CRM

Самостоятельный прототип интерфейса для логистической CRM. **Не копия** рабочей системы: это новый визуальный язык, собранный с нуля.

- План: [`PLAN.md`](PLAN.md)
- Матрица паритета (ничего не теряем): [`PARITY.md`](PARITY.md)

## Что это

Светлый лавандовый интерфейс с фиолетовыми градиентами, пастельными плитками иконок и насыщенными карточками сделок. Тёмная тема, три варианта акцента, переключаемая плотность.

Экраны: воронка лидов (стартовый), карточка лида, клиенты, заявки и карточка заявки, задачи, аналитика, бухгалтерия, настройки.

Входа и авторизации в макете нет — приложение открывается сразу внутри системы.

## Запуск

Нужен Node.js LTS с [nodejs.org](https://nodejs.org) (MSI, `winget` не требуется).

```bash
npm install
npm run dev
```

Открыть `http://localhost:5173`.

## Что уже собрано

- Токены светлой и тёмной темы (`src/styles/tokens.css`)
- Типографика: Inter Tight, Inter, JetBrains Mono
- Оболочка: рельс модулей, командная строка, рабочая область (`src/app/Shell.jsx`)
- Базовые элементы: кнопки, поля, поиск, теги, статусы, чипы, сегменты, аватары, карточки, таблица, модалка, пустые состояния, скелетоны (`src/ui/*`)
- Витрина дизайн-системы: `/kit`
- Переключатели темы, акцента и плотности (запоминаются в браузере)
- Воронка: KPI с цветными полосами, колонки этапов, карточки с маршрутом, грузом, суммой и сроком
- Карточка лида: этапы, клиент, контакты, заявки, файлы, история, бюджет
- Клиенты и заявки: таблицы со статусами и маржой, карточка заявки с деньгами
- Задачи: четыре колонки, отметка «выполнено», фильтры, создание задачи
- Аналитика: период, воронка, график поступления, рейтинг менеджеров, источники
- Настройки: тема, акцент, плотность, редактор этапов
