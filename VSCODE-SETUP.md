# Полная настройка проекта в VS Code — по шагам

Инструкция для Windows. Node.js, Python и Git **не нужны** — достаточно VS Code
и расширения Live Server.

Время: ~10 минут. Итог: сайт открывается по адресу `http://127.0.0.1:5500`
и сам перезагружается при сохранении файлов.

---

## Шаг 0. Что понадобится

- Windows 10 или 11;
- интернет (скачать VS Code и проект);
- ~200 МБ на диске.

---

## Шаг 1. Установить VS Code

1. Откройте **https://code.visualstudio.com/** и нажмите большую кнопку
   **Download for Windows**.
2. Запустите скачанный файл `VSCodeUserSetup-x64-....exe`.
   Если Windows покажет синее окно «Windows protected your PC» —
   нажмите **More info / Подробнее** → **Run anyway / Выполнить всё равно**.
3. В установщике оставьте всё по умолчанию и нажмите **Next** несколько раз,
   затем **Install** → **Finish**.
   Полезно оставить галочки «Add to PATH» и «Add "Open with Code" action»
   (первая обычно уже отмечена).
4. Запустите VS Code (иконка в меню «Пуск»).

Проверка: открылось тёмное окно с надписью **Welcome / Добро пожаловать**.

> Язык интерфейса: если VS Code на английском, а хочется на русском —
> `Ctrl + Shift + X` → найдите **Russian Language Pack** → Install → перезапустить.
> В инструкции ниже указаны оба варианта названий.

---

## Шаг 2. Скачать проект

Скачайте архив с актуальной версией проекта:

**https://github.com/Roses1s/rebrand/archive/refs/heads/arena/53b90abe-rebrand.zip**

Браузер сохранит файл `rebrand-arena-53b90abe-rebrand.zip` в папку «Загрузки».
Не открывайте его внутри браузера — он должен лежать на диске.

---

## Шаг 3. Распаковать и проверить структуру

1. Откройте «Загрузки» в Проводнике.
2. Правый клик по архиву → **Извлечь всё… / Extract All…** → **Extract**.
3. Переименуйте получившуюся папку в короткое имя без пробелов, например `rebrand`,
   и при желании перенесите её, скажем, в `C:\Users\ВашеИмя\rebrand`.
   (Длинный путь с пробелами и кириллицей тоже работает, но короткий надёжнее.)
4. Зайдите внутрь папки и убедитесь, что видите:

```
index.html
crm-standalone.html
README.md
build.mjs
serve.mjs
serve.ps1
assets\          → styles.css, app.js
.vscode\         → settings.json, extensions.json   (скрытая папка)
```

Если папки `.vscode` не видно — включите её отображение:
в Проводнике вкладка **Вид / View** → **Показать / Show** → **Скрытые элементы / Hidden items**.

> Папки `.vscode` может и не быть (если ранее скачивали проект по частям) — это не критично,
> Live Server всё равно запустится на порту 5500. Но с ней порт и автосохранение
> настроены автоматически.

---

## Шаг 4. Открыть папку в VS Code

1. В VS Code: меню **File → Open Folder… / Файл → Открыть папку…**
   (`Ctrl + K`, затем `Ctrl + O`).
2. Выберите папку `rebrand` (ту, где лежит `index.html`) и нажмите
   **Select Folder / Выбрать папку**.
3. Появится вопрос про доверие: **«Do you trust the authors of the files in this folder?»** —
   нажмите **Yes, I trust the authors / Да, я доверяю авторам**.
   (Это стандартный запрос VS Code для любой папки.)

Проверка: слева в панели **Explorer / Проводник** виден список файлов проекта,
а в заголовке окна — `rebrand - Visual Studio Code`.

⚠️ Важно: открывать нужно **папку**, а не отдельный файл `index.html`.
Если вы дважды щёлкнули по `index.html`, VS Code откроет только его — закройте
и повторите шаг 4 через **File → Open Folder**.

---

## Шаг 5. Установить расширение Live Server

1. Нажмите `Ctrl + Shift + X` (панель **Extensions / Расширения**).
2. В поле поиска введите **Live Server**.
3. Первым в списке будет расширение **Live Server** от автора **Ritwick Dey**
   (иконка с фиолетовым/синим кружком). Нажмите **Install**.
4. Дождитесь надписи **Installed / Установлено**.

> Если при открытии папки VS Code сам показал внизу справа
> «Do you want to install recommended extension Live Server?» — можно нажать
> **Install** и пропустить этот шаг.
> Расширение автоматически не запускается — это нормально.

---

## Шаг 6. Запустить сайт

Способ А — кнопка в строке состояния:

- в **правом нижнем углу** окна найдите **Go Live** и нажмите её.

Способ Б — через контекстное меню:

- в панели Explorer щёлкните **правой кнопкой** по `index.html` →
  **Open with Live Server / Открыть с помощью Live Server**.

Что произойдёт:
1. В строке состояния появится `Port: 5500`.
2. Автоматически откроется браузер с адресом **http://127.0.0.1:5500**.
3. Загрузится страница «Лиды» с канбан-доской.

Если браузер не открылся — скопируйте адрес вручную: `http://127.0.0.1:5500`.

---

## Шаг 7. Проверить, что всё работает

Пройдитесь по чек-листу прямо в браузере:

- [ ] Заголовок вкладки: **ТрансЛайн CRM — Лиды**;
- [ ] слева меню с пунктом **Лиды** (подсвечен);
- [ ] 6 колонок: Новый · Перезвонить · Вышел на ЛПР · Потенциальный · Уехали · Ждем заявку;
- [ ] в колонках 20 карточек с маршрутами и суммами;
- [ ] сверху 4 KPI-карточки (лидов в работе, сумма воронки, средний чек, конверсия);
- [ ] переключатель-свитч справа вверху меняет светлую/тёмную тему;
- [ ] карточку можно перетащить мышкой в другую колонку;
- [ ] клик по карточке открывает боковую панель с деталями;
- [ ] кнопка **Новый лид** открывает форму создания;
- [ ] клик по «Заявки», «Грузы» и т. п. показывает уведомление «раздел в разработке».

Если все пункты выполняются — настройка завершена.

## Шаг 8. Как вносить изменения

| Что меняем | Файл |
|---|---|
| Тексты, структура страницы, колонки | `index.html` |
| Цвета, отступы, темы, адаптив | `assets/styles.css` |
| Лиды, этапы, менеджеры, логика | `assets/app.js` |

Порядок работы:

1. Откройте файл двойным щелчком в панели Explorer.
2. Внесите правку.
3. Нажмите **`Ctrl + S`** (сохранить). В проекте включено автосохранение через 0,8 с,
   но привычнее сохранять вручную.
4. Браузер обновится сам за долю секунды — это и есть Live Server.
   Если не обновился: `Ctrl + F5` в браузере.

Замечания:
- Данные лидов лежат в `assets/app.js` в массиве `leads` — можно править суммы,
  города, добавлять карточки вручную.
- Любая перезагрузка страницы возвращает исходные 20 лидов: состояние хранится
  в памяти, а не в базе. (Можно включить сохранение в localStorage — скажите, добавлю.)
- Файл `crm-standalone.html` — отдельная сборка «всё в одном». Для работы через
  VS Code он не нужен, но если хотите его обновить после своих правок,
  потребуется Node.js: `node build.mjs`.

## Шаг 9. Как получать обновления проекта

Обновления, которые делаю я, публикуются в ветке `arena/53b90abe-rebrand`
на GitHub. Проект, скачанный ZIP-архивом, сам не обновляется.

### Способ А (проще): скачать архив заново

1. Скачайте ZIP по той же ссылке (Шаг 2).
2. Распакуйте и скопируйте файлы **поверх** папки `rebrand` с заменой.
   `index.html`, `assets`, `.vscode` заменятся, ваши личные правки в них — тоже
   (если они были, лучше сохранить копию).
3. В браузере нажмите `Ctrl + F5`.

### Способ Б (удобнее, нужен Git): обновление одной командой

1. Установите Git: в PowerShell выполните
   ```powershell
   winget install Git.Git
   ```
   затем перезапустите VS Code.
2. Один раз склонируйте проект (вместо Шага 2–3):
   ```powershell
   cd C:\Users\ВашеИмя
   git clone -b arena/53b90abe-rebrand https://github.com/Roses1s/rebrand.git
   ```
3. Дальше обновление = одна команда в терминале VS Code
   (меню **Terminal → New Terminal**, `Ctrl + ~`):
   ```powershell
   git pull
   ```
   Или без консоли: панель **Source Control** (`Ctrl + Shift + G`) → меню `⋯` → **Pull**.
4. Страница обновится сама (или `Ctrl + F5`).

## Шаг 10. Как остановить и закрыть

- Остановить сервер: нажмите **Port: 5500** в правом нижнем углу строки состояния
  (появится уведомление, что сервер остановлен). Или просто закройте VS Code.
- Закрыть проект: **File → Close Folder / Файл → Закрыть папку**.
- Браузерную вкладку можно закрыть в любой момент — сервер продолжит работать,
  пока открыт VS Code.

## Если что-то пошло не так

| Проблема | Причина и решение |
|---|---|
| Нет кнопки **Go Live** | Расширение не установлено (Шаг 5) или открыт отдельный файл, а не папка (Шаг 4) |
| **Go Live** есть, но браузер не открылся | Откройте вручную `http://127.0.0.1:5500` |
| `Port 5500 is already in use` | Уже запущен другой Live Server/сервер. Нажмите **Port: 5500** и остановите старый, либо ответьте **Yes** на предложение взять другой порт |
| Открылась страница со списком файлов вместо сайта | `index.html` лежит не в корне открытой папки — откройте именно папку `rebrand` |
| Страница без стилей, «голый» текст | В папке нет `assets` — архив распакован не целиком, распакуйте заново |
| Изменения не видны | Файл не сохранён (`Ctrl + S`) или кэш браузера (`Ctrl + F5`) |
| Браузер открывает `file:///...` | Вы открыли `index.html` двойным щелчком, а не через **Go Live** |
| «Restricted Mode» внизу окна | Нажмите **Manage Trust** / **Trust** и разрешите доверие папке (Шаг 4) |
| VS Code пишет «Cannot find module» | Это про `build.mjs`: для Live Server Node.js не нужен, просто не запускайте этот файл |

## Если VS Code не подходит

В проекте остались альтернативы, не требующие ничего устанавливать:

- `crm-standalone.html` — весь сайт в одном файле, открывается двойным щелчком;
- `Запустить на Windows.bat` — локальный сервер на встроенном PowerShell,
  адрес `http://localhost:8000`, права администратора не нужны.
